# Byung-cheol Kang — Bioinformatics Portfolio

Source for [bruce-bc.github.io](https://bruce-bc.github.io), built with the stable al-folio v1.2 starter and deployed through GitHub Pages.

## Content

- Education, experience, skills, and downloadable CV
- Seven SCI(E) publications and one joint patent contribution
- Project case studies with Mermaid workflows, evidence, and limitations
- Public GitHub repositories

## Local preview

```bash
docker compose up
```

The site is then available at `http://localhost:8080`.

## Deployment

Pushing to `master` runs the GitHub Actions deployment workflow and publishes the generated site to the `gh-pages` branch.
